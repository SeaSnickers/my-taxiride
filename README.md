# my taxiride
lab 3 simple test for taxi server 

# how to use:
1. In an IDE such as Apache NetBeans, create a project with the name: Taxiride and then run it.
2. Input your name.
3. Input the distance you want to travel. Only use numbers.
4. Input how long you want it to take. Only use integers.
5. Enter, and have a fun ride.
